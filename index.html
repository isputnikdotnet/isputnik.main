Self-hosted web app

isputnik.home

Open source home server for family accounts, notes, sharing, and a digital audiobook library.

  • Self-hosted on your own machine or home server
  • Designed for a private home network and trusted users
  • Keeps media, metadata, and backups under your control
GitHub repository

Android audiobook player

isputnik.player

Code name: iSputnik Laika

Kotlin/Compose player for audiobooks, bookmarks, progress, and offline listening.

  • Plays local audiobook files on Android
  • Connects to isputnik.home when a server is available
  • Downloads books from home for offline listening
