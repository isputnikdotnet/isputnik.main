Highlights

Built to keep, safe to share.

The parts you only notice once the library is real: getting it all back, letting only the right people in, and maps that don't depend on someone else's server.

Everything back, on any machine.

Backups run while the server keeps serving, and each one downloads as a single file you can restore on a fresh install.

  • Three kinds

    A full backup carries the database and every cover and preview, so a restore needs no re-render. A minimal one carries only what a rescan could not put back. A quick copy is the database file alone.

  • Each on its own clock

    Full weekly and minimal nightly, say, each keeping its own number of copies. The database is also copied before every upgrade.

  • Your files where you put them

    One SQLite database beside your own folders, and the media in them is never modified. Anything deleted waits in a Recycle Bin.

Security for access beyond home.

One page scores the whole install out of 100 and grades every policy behind the number. Each row opens the setting that owns it.

  • Two-factor sign-in

    An authenticator app or an emailed code, and passkeys for the people who have them. It can be required only from outside the house.

  • Lockout and blocking

    Repeated failures lock the account and, if they keep coming, block the address. Rate limits and a strict Content Security Policy sit underneath.

  • Someone is told

    An email to the admin when a sign-in comes from somewhere new, and a full activity log to check afterwards.

Maps that keep working without the internet.

Photo maps, the family map and story routes share one set of map features. Each is a card with a switch that says what it downloads, and how much room it takes, before it does.

  • Offline maps

    The server keeps the maps you've viewed, up to a limit you choose. They draw with the connection down, and the map service no longer sees where you look.

  • Place names, built at home

    Each photo named after the town it was taken in, from a GeoNames database built on your server. No photo's location is sent anywhere.

  • Where sign-ins came from

    Addresses placed on the Dashboard map from a database on the server, never looked up online.
